# ✨ Inner Notes

Inner Notes é um aplicativo desenvolvido em Python com Streamlit que gera frases motivacionais e reflexivas para diferentes momentos do dia.

## Objetivo

Este projeto foi criado como parte da minha jornada de aprendizado em Python e desenvolvimento de aplicações.

Além de praticar programação, o objetivo foi construir um projeto real que pudesse ser compartilhado com outras pessoas e fazer parte do meu portfólio.

## Funcionalidades

* Frases de foco
* Frases de recomeço
* Frases de autoestima
* Frases para estudos
* Seleção de categoria
* Geração aleatória de frases

## Tecnologias Utilizadas

* Python
* Streamlit
* GitHub

## O que aprendi

Durante o desenvolvimento deste projeto pratiquei:

* Variáveis
* Listas
* Condicionais (if, elif, else)
* Funções da biblioteca random
* Organização de código
* Publicação de projetos no GitHub
* Introdução ao Streamlit
